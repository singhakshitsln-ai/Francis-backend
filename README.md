# Francis Cyber Toolkit

Offline-first cyber utility toolkit with:

- Matrix animated background
- Installable PWA
- Hover cards
- SHA-256 hasher
- Password generator
- UUID generator
- Base64 tools
- JSON formatter
- Word counter
- Character counter
- Text-to-speech
- Local notes saver
- Backend API support

Frontend:
Deploy with GitHub Pages.

Backend:
Deploy with Render.
